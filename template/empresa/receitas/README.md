# Receitas

Receita é uma solução que já funcionou para um cliente e pode ser repetida no próximo: um
modelo de proposta, uma automação, um roteiro de reunião, uma planilha.

**Antes de fazer algo do zero, procure aqui.**

Uma receita por arquivo, com: o problema que resolve, o passo a passo, o que adaptar de um
cliente para outro e onde ela já foi usada.
